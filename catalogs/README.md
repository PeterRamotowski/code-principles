# Foundation Catalogues

These catalogues define the controlled components. Catalogue entries remain the source of identifiers and
available modes; implemented components also have normative metadata and guidance in their own directory.

- `core-skills.yaml` groups principles into operational decision Skills.
- `profiles.yaml` lists language-independent project profiles.
- `modifiers.yaml` lists cross-cutting constraints.
- `languages.yaml` includes JavaScript, TypeScript, Python, PHP, Go, and C++.
- `frameworks.yaml` includes React, Next.js, Angular, Vue, Nuxt, Symfony, and Drupal.

A catalogue entry alone is a blueprint identifier, not a completed Skill. The Milestone 4 Core Skills are
implemented under `core/`; later components remain blueprints until they receive their own normative
document, metadata, examples, and evaluations.
